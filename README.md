# Market Dashboard 学習リポジトリ

TypeScriptとReactで、架空の相場データを検索・比較するMarket Dashboardを実装するための学習用リポジトリです。

## 構成

- [`docs/typescript-react-30h.html`](docs/typescript-react-30h.html): 30時間の学習教材
- [`src/`](src): Vite + React + TypeScriptで作るアプリケーション

## 開始方法

教材HTMLをブラウザーで開き、H01から進めます。アプリケーションはリポジトリ直下から起動します。

```sh
npm run dev
```

## 検証

```sh
npm run typecheck
npm run lint
npm run build
```

Node.js 24系を使用します。進捗は作業ごとにコミットし、`git push` でGitHubへ同期します。
