H03

null・undefined・unknownを境界で扱う

読解15分 / 実装30分 / 検証10分 / 自己説明5分

欠損と不正入力を、値の真偽と混同せずに表す。

このアプリのpriceはnumber | nullとする。欠損をnullに統一し、オブジェクトにキーがない状態とは区別する。strictNullChecksに加えてnoUncheckedIndexedAccessを有効にし、配列の添字アクセスにもundefinedの可能性を反映させる。exactOptionalPropertyTypesでは任意プロパティの省略とundefinedの明示代入の差も現れる。

unknownは「使う前に絞り込む」という契約に向く。anyはその検査を通り抜ける。0を欠損扱いするif (price)やprice || fallbackを避け、null判定または??を使う。typeof nullがobjectである点も、オブジェクト検証では忘れない。

コードで確かめる

function showPrice(value: number | null): string {
  return value === null ? "—" : value.toFixed(2);
}
const zero = 0;
console.log(zero || 999); // 999
console.log(zero ?? 999); // 0
function isRecord(x: unknown): x is Record<string, unknown> {
  return typeof x === "object" && x !== null && !Array.isArray(x);
}

この1時間で実装すること

src/domain/format.tsにshowPriceを書く。null、0、12.345を入力して確認する。任意プロパティ foo?: number と foo: number | undefined を比較する。配列先頭を非nullアサーションなしで取り出す。

完了条件：nullは—、0は0.00になる。空配列を扱える。unknownのプロパティに検査なしでアクセスしていない。

自己説明テスト

price?: number と price: number | null のうち、「キーは必ず存在し、値が欠損しうる」という今回の契約はどちらか。

回答してから解説を開く

後者。前者はキーの省略を許す。数値0の有効性と欠損は別の軸であり、truthinessで判定するとその区別が壊れる。

H04

判別可能なUnionとnever

読解15分 / 実装30分 / 検証10分 / 自己説明5分

通信状態を矛盾のない状態集合として設計する。

loading:booleanとerror?:stringとdata?:Tを独立させると、loadingとerrorが同時に真などの組合せが表現できてしまう。statusという判別子を持つUnionなら、その分岐に必要な値を一緒に定義できる。これはUI状態を有限の集合として扱う設計である。

switchでstatusを絞り込むと、成功分岐だけでdataが使える。全分岐を処理した後の値はneverになるので、新状態を追加した際に未対応箇所を検出できる。例外は外部境界で受け、UIへは明示的なerror状態として渡す方針にする。

コードで確かめる

type Remote<T> =
  | { status: "loading" }
  | { status: "success"; data: T }
  | { status: "error"; message: string };
function unreachable(x: never): never {
  throw new Error(`Unhandled state: ${JSON.stringify(x)}`);
}
function describe<T>(s: Remote<T>): string {
  switch (s.status) {
    case "loading": return "読込中";
    case "success": return "読込成功";
    case "error": return s.message;
    default: return unreachable(s);
  }
}

この1時間で実装すること

model.tsにRemote<T>を追加する。既存の3状態をdescribeで処理する。その後一時的に { status: "idle" } を追加し、網羅性エラーを観察してから戻す。

完了条件：success以外でdataが参照できない。idle追加でコンパイラーが未対応を検出する。

自己説明テスト

loadingとerrorの独立したbooleanをUnionに置き換える利点は、短く書けることだけか。

回答してから解説を開く

本質は不正な組合せを表現しにくくすること。UIの分岐ごとに利用可能なデータが対応し、状態追加時の漏れも検出できる。

H05

readonly・分割代入・配列操作

読解10分 / 実装25分 / 検証5分 / 自己説明5分 / 章末15分

参照共有と浅いコピーを理解し、純粋な集計関数を作る。

readonlyはその型を通じた書き換えを静的に制限するもので、実行時の深い凍結ではない。スプレッドも浅いコピーなので、配列だけを複製して要素オブジェクトを書き換えると元の要素が変わりうる。Reactの状態更新へ進む前に参照図を自分で追う。

Arrayのfilterとmapは通常の配列を直ちに返す。この教材ではLINQの遅延評価を期待しない。sortは元配列を変更し、比較関数を省略すると数値の大小順にはならない。コピーしてから比較関数付きでソートする。

コードで確かめる

const values = [3, 20, 100];

import type { Point, Quote } from "../domain/model";
function isRecord(x: unknown): x is Record<string, unknown> {
  return typeof x === "object" && x !== null && !Array.isArray(x);
}
function isPrice(x: unknown): x is number | null {
  return x === null || (typeof x === "number" && Number.isFinite(x) && x > 0);
}
function isText(x: unknown): x is string {
  return typeof x === "string" && x.trim().length > 0;
}
function isDate(x: unknown): x is string {
  if (typeof x !== "string" || !/^\d{4}-\d{2}-\d{2}$/.test(x)) return false;
  const d = new Date(x + "T00:00:00Z");
  return Number.isFinite(d.getTime()) && d.toISOString().slice(0, 10) === x;
}
function isPoint(x: unknown): x is Point {
  return isRecord(x) && isDate(x.date) && isPrice(x.close);
}
function parseQuote(x: unknown, row: number): Quote {
  if (!isRecord(x) || !isText(x.id) || !isText(x.symbol) || !isText(x.name)
      || (x.kind !== "equity" && x.kind !== "etf") || x.currency !== "USD"
      || !isPrice(x.price) || !isPrice(x.previousClose)
      || !Array.isArray(x.history)) {
    throw new Error(`row ${row}: invalid quote`);
  }
  const history: Point[] = x.history.map((p: unknown, i: number) => {
    if (!isPoint(p)) throw new Error(`row ${row}, point ${i}: invalid point`);
    return { date: p.date, close: p.close };
  });
  for (let i = 1; i < history.length; i++) {
    const previous = history[i - 1];
    const current = history[i];
    if (previous && current && previous.date >= current.date)
      throw new Error(`row ${row}: dates must be unique and ascending`);
  }
  const last = history[history.length - 1];
  const previous = history[history.length - 2];
  if (last && last.close !== x.price)
    throw new Error(`row ${row}: price does not match last close`);
  if (previous && previous.close !== x.previousClose)
    throw new Error(`row ${row}: previousClose mismatch`);
  return { id: x.id, symbol: x.symbol, name: x.name, kind: x.kind,
    currency: x.currency, price: x.price, previousClose: x.previousClose, history };
}
export function parseQuotes(raw: unknown): readonly Quote[] {
  if (!Array.isArray(raw)) throw new Error("Expected a quote array");
  const ids = new Set<string>();
  const symbols = new Set<string>();
  return raw.map((x: unknown, i: number) => {
    const q = parseQuote(x, i);
    if (ids.has(q.id) || symbols.has(q.symbol))
      throw new Error(`row ${i}: duplicate id or symbol`);
    ids.add(q.id); symbols.add(q.symbol);
    return q;
  });
}

import type { Quote, Filter, Sort } from "./model";
export function changePct(q: Quote): number | null {
  if (q.price === null || q.previousClose === null || q.previousClose <= 0)
    return null;
  return (q.price / q.previousClose - 1) * 100;
}
export function compareNullable(a: number | null, b: number | null,
  direction: "asc" | "desc"): number {
  if (a === null) return b === null ? 0 : 1;
  if (b === null) return -1;
  return direction === "asc" ? a - b : b - a;
}
export function selectQuotes(rows: readonly Quote[], filter: Filter, sort: Sort) {
  const term = filter.query.trim().toLowerCase();
  const filtered = rows.filter(q =>
    (filter.kind === "all" || q.kind === filter.kind) &&
    (q.symbol.toLowerCase().includes(term) || q.name.toLowerCase().includes(term))
  );
  return [...filtered].sort((a, b) => {
    if (sort.key === "symbol") return sort.direction === "asc"
      ? a.symbol.localeCompare(b.symbol) : b.symbol.localeCompare(a.symbol);
    const av = sort.key === "price" ? a.price : changePct(a);
    const bv = sort.key === "price" ? b.price : changePct(b);
    return compareNullable(av, bv, sort.direction) || a.symbol.localeCompare(b.symbol);
  });
}
